# Paddy-Crop-Disease-Detection

After successfully importing in your system,
for executing follow the steps:
  1. Open command prompt.
  2. Write "cd", with cd paste the path of the file.
  3. Then write command "npm install".
  4. Then write command "npm run dev".
  5. After this, we will be getting a link.
  6. That link will be of localhost.
  7. Then ctrl + right click on the link.
  8. And boom, your project is ready!
